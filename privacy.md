# Informativa sulla Privacy

Ultimo aggiornamento: 2026-11-08

La presente informativa sulla privacy descrive come vengono gestiti i dati quando utilizzi la nostra applicazione "Drive per r-clone".

## 1. Raccolta delle Informazioni
La nostra Applicazione è progettata per uso personale o di test. Non raccogliamo, memorizziamo o condividiamo alcuna informazione personale identificabile degli utenti al di fuori di quanto strettamente necessario per il funzionamento tecnico dell'applicazione stessa (tramite le API di Google).

## 2. Utilizzo dei Dati di Google
Se l'Applicazione richiede l'accesso al tuo Account Google (tramite autenticazione OAuth), i dati a cui si accede vengono utilizzati esclusivamente per fornire le funzionalità richieste dall'applicazione sul tuo dispositivo locale. Nessun dato personale o token di accesso viene ceduto a terzi o memorizzato su server remoti esterni.

## 3. Sicurezza
Adottiamo misure di sicurezza ragionevoli per proteggere le informazioni trattate o memorizzate dall'Applicazione. Tuttavia, nessun metodo di trasmissione su Internet o di archiviazione elettronica è sicuro al 100%.

## 4. Modifiche a questa Informativa sulla Privacy
La presente Informativa sulla Privacy può essere aggiornata periodicamente. Eventuali modifiche saranno pubblicate direttamente su questa pagina all'interno del repository GitHub.

## 5. Contatti
Per qualsiasi domanda o chiarimento in merito alla presente informativa, puoi contattare il proprietario del repository GitHub associato a questa applicazione.
